## 1. البرومت الأول: مواصفة المنتج

منتج ويب عربي يعمل من المتصفح. المستخدم يكتب سؤالًا واحدًا، ويرفق ملفات عند الحاجة، ويختار النماذج، ويرى النتائج جنبًا إلى جنب. الموقع مجاني للمستخدم ضمن حصص قابلة للإدارة. المطلوب منتج مترابط بنتائج حقيقية، لا واجهة ببيانات وهمية.

### الشكل والمنصة

- [ ] تطبيق متصفح فقط، للجوال والتابلت والكمبيوتر. لا تطبيق Android أو iOS، ولا SDK خاص بتطبيقات الجوال.
- [ ] اللغة الافتراضية العربية، والاتجاه RTL.
- [ ] إن كان المشروع جديدًا: React وTypeScript وNext.js بإصدار مستقر ومدعوم وقت التنفيذ، وTailwind CSS وshadcn/ui مع RTL، وقاعدة دائمة، وتخزين ملفات خاص، ومهام خلفية، ومخزن حصص وطوابير مشترك لا يعتمد على ذاكرة عملية واحدة.
- [ ] الواجهة تبقى سريعة. زمن مزود النموذج يُقاس منفصلًا عن زمن الواجهة، ولا يُوعد بزمن ثابت للنماذج المجانية.
- [ ] لا نشر عام، ولا تفعيل خدمة مدفوعة، قبل عرض النسخة المكتملة ومتطلبات تشغيلها على المالك.

### الدخول وGoogle

- [ ] Google Identity Services للويب حصرًا. التوثيق: [نظرة GIS](https://developers.google.com/identity/gsi/web/guides/overview) و[التحقق من ID token](https://developers.google.com/identity/gsi/web/guides/verify-google-id-token).
- [ ] لا رابط Android ولا مكتبات Android.
- [ ] الدخول شرط لاستخدام النماذج ورفع الملفات. لا كلمات مرور ولا ضيف لمسارات الاستهلاك.
- [ ] الخادم يتحقق من ID token، بما في ذلك التوقيع و`aud` و`iss` و`exp`، مع CSRF وnonce حسب التدفق المعتمد.
- [ ] معرف الحساب الثابت هو `sub` مع مزود Google، لا البريد وحده.
- [ ] جلسة بخادم، وملفات ارتباط `HttpOnly` و`Secure` و`SameSite` مناسبة. لا رموز مصادقة في `localStorage`.
- [ ] الاسم والبريد المعروضان يأتيان من هوية Google المتحقَّق منها.
- [ ] بعد أول دخول: الجوال مطلوب ويُوحَّد إلى E.164، ولا يصبح «متحقق» إلا بعد OTP ناجح من مزود رسائل حقيقي. العمر والمدينة اختياريان ولا يُستنتجان.
- [ ] إن غابت إعدادات مزود الرسائل، لا يُدّعى اكتمال التحقق الحي، ولا تُستخدم رموز اختبار في الإنتاج.

### Turnstile

- [ ] الودجت الحالي يُعاد استخدامه. لا ودجت بديل، ولا تغيير تلقائي للنطاقات أو النمط.
- [ ] المفتاح العام للموقع: `0x4AAAAAAFoJLWRjfC1ZYlwB`.
- [ ] اسم متغير السر على الخادم: `TURNSTILE_SECRET_KEY`. القيمة السرية لا تُكتب في الكود ولا في الوثائق ولا في المستودع ولا في السجلات.
- [ ] Invisible فعلًا في إعداد الودجت: بلا checkbox وبلا تحدٍ مرئي. لا يُحوَّل Managed إلى Invisible عبر CSS.
- [ ] السكربت الرسمي: `https://challenges.cloudflare.com/turnstile/v0/api.js`.
- [ ] التحقق من الخادم: `POST https://challenges.cloudflare.com/turnstile/v0/siteverify`، مع `success === true` و`action` المتوقع و`hostname` ضمن نطاقات البيئة.
- [ ] فشل التحقق أو تعذر الاتصال يوقف العملية المحمية. لا تجاوز صامت.
- [ ] الرمز صالح لخمس دقائق ويُستخدم مرة واحدة. تحقق واحد عند إنشاء المقارنة، لا لكل نموذج ولا لكل دفعة بث.
- [ ] Turnstile لا يغني عن المصادقة أو الحصص أو الصلاحيات. نطاقات الإنتاج لا تشمل localhost.

### المفتاح والسجل المجاني

- [ ] كل طلبات OpenRouter من الخادم بمفتاح المالك. المتصفح لا يستلم المفتاح، والمستخدم لا يُطلب منه إدخاله.
- [ ] اسم المتغير: `OPENROUTER_API_KEY`. القيمة تبقى خارج Git وخارج الوثائق.
- [ ] نقاط مجانية فقط. لا تحول تلقائي إلى نموذج أو مزود مدفوع، ولا تفعيل تلقائي لـ Pro أو إضافة مدفوعة، بما في ذلك OCR والبحث والأدوات المدفوعة.
- [ ] لا استبدال صامت لنموذج اختاره المستخدم، ولو تشابهت الأسماء أو تعطل النموذج أو بطؤ.
- [ ] سجل نماذج مركزي على الخادم. الواجهة تقرأ البيانات العامة اللازمة فقط. allowlist على الخادم تمنع `model id` عشوائيًا.
- [ ] إدراج النموذج في السجل لا يعني تفعيله للجمهور. تُحترم شروط نقطة الخدمة، وتُعرض حالة واضحة، ولا يُحذف النموذج من السجل بسبب قيد مؤقت.
- [ ] `openrouter/free` خيار توجيه مجاني مستقل خارج المقارنة المضبوطة. إن استُخدم، يُعرض النموذج الذي عالج الطلب عندما تعيده الاستجابة. هو ليس بديلًا صامتًا.
- [ ] التضمين الافتراضي: `nvidia/nemotron-3.5-embed-1b:free` عند سماح شروط نقطته. `nvidia/nemotron-3.5-embed-8b:free` بديل مقارنة للاسترجاع، لا يستبدل 1B.

### المقارنة والملفات والحصص

- [ ] السؤال نفسه، والتعليمات الأساسية نفسها، ولغة الإجابة نفسها. في المقارنة المستقلة لا يرى نموذج إجابة منافس.
- [ ] وضعان معلنان: «مقارنة بمدخلات موحدة» و«مقارنة بالقدرات الأصلية». لا تُوصف المدخلات بالمتطابقة إذا اختلفت.
- [ ] النتائج تُبث تدريجيًا وبشكل مستقل. تعطل نموذج واحد لا يوقف البقية. لا تقييم جودة مختلق.
- [ ] مسار الملفات: تحقق من المحتوى لا من الامتداد فقط، حفظ الأصل في تخزين خاص، استخراج مرة واحدة مع معلومات المصدر، ومنع إسقاط الصفحات أو الأوراق أو ملفات ZIP بصمت.
- [ ] الصيغ الدنيا تشمل الصور وPDF وDOC/DOCX وTXT/Markdown وJSON وCSV/TSV وXLS/XLSX وZIP والشيفرة، والصوت والفيديو عبر المسارات المدعومة فعلًا.
- [ ] لا macros ولا روابط خارجية في الجداول. فك ZIP آمن بلا تنفيذ لمحتواه. لا قص صامت للملفات الكبيرة.
- [ ] مسار البحث الافتراضي: استخراج، ثم تقسيم بالمصدر، ثم Embed 1B إذا سمحت الشروط، ثم استرجاع، ثم Rerank اختياري، ثم أدلة مشتركة، ثم نماذج الإجابة.
- [ ] فهارس التضمين منفصلة لكل نموذج وإعداد أبعاد وإصدار معالجة.
- [ ] Fish يحوّل النص المختار إلى صوت، ولا يُقدَّم كنموذج يجيب عن السؤال.
- [ ] حصص حساب ومستخدم، وتزامن، وطابور عادل، وحجز ذري قبل الإرسال، وidempotency، ومعالجة 429 مع `Retry-After` وإعادة محاولات محدودة.
- [ ] المقارنة الواحدة عدة استدعاءات. تُحتسب التضمين والتقييم والصوت وإعادة المحاولة. لا تعدد مفاتيح للتحايل على حدود المزود.
- [ ] الخادم يتحقق بالترتيب من الجلسة، ثم اكتمال الحساب، ثم الصلاحية، ثم Turnstile عند العملية المطلوبة، ثم الحصة، ثم ملاءمة النموذج وسياسة استخدامه، ثم التنفيذ.
- [ ] لا أسرار في حزمة المتصفح أو السجلات. لا تنفيذ لتعليمات داخل الملفات كتعليمات نظام. HTML وMarkdown المعروضان مُعقَّمان.

## 2. البرومت الثاني: MAX_QUALITY_FREE

النص الكامل في `docs/max-quality-free-policy.md`.

- [ ] ملف الإعداد المركزي اسمه `MAX_QUALITY_FREE`، ويُحسب لكل نموذج من بيانات نقطته، لا كقيمة `effort` واحدة تُرسل للجميع.
- [ ] الأولوية لجودة الإجابة ودقتها واكتمالها. الواجهة تبقى سريعة، وزيادة زمن النموذج مقبولة.
- [ ] أعلى تحكم مجاني مدعوم ومُتحقق منه فقط. بلا معاملات مخترعة، وبلا خفض صامت للجودة، وبلا نقل إلى خدمة مدفوعة.

## 3. ملحق Claude Haiku 5.5

النص الكامل في `docs/haiku-5-5-addendum.md`.

- [ ] `claude-haiku-5-5` عبر Anthropic مباشرة جزء من النماذج التي يستطيع المنتج تشغيلها، إلى جانب السجل المجاني.
- [ ] النموذج مدفوع وتُحاسب تكلفته منفصلة. لا يُفعَّل نموذج Anthropic آخر، ولا يُستبدل صامتًا بنموذج OpenRouter مجاني.
- [ ] عند اختيار المستخدم له: تفكير Adaptive، و`output_config.effort` = `medium`.
- [ ] سياسة `MAX_QUALITY_FREE` لا ترفع هذا الجهد، ولا تحوّل إليه طلبات النماذج المجانية.
